# MouseGestures Project

## Purpose
A macOS application for mouse gesture recognition and action automation, allowing users to perform actions through mouse movements and gestures.

## Tech Stack
- **Language**: Swift 5
- **UI Framework**: SwiftUI
- **Target Platform**: macOS 13.0+
- **Build System**: Xcode/xcodebuild
- **Architecture**: Plugin-based modular architecture

## Key Features
- Mouse gesture detection and recognition
- Profile management system
- Plugin-based action system
- Condition-based detection
- Import/Export functionality

## Code Architecture
- **Action Plugins**: Modular plugin system for actions
- **Detection Plugins**: Modular plugin system for gesture detection
- **Profile Management**: Configuration profiles for different gesture sets
- **UI Services**: Service layer for UI components
- **Configuration**: Profile and gesture configuration management
