MOUSEGESTURES - ALL AVAILABLE ACTIONS
======================================
Last updated: 2026-03-03

Legend: [✓] = Done, [!] = Bug/Issue, [TODO] = Planned change

--------------------------------------
CORE ACTIONS (com.mousegestures.core)
--------------------------------------
close_window         - Close a window
	* Supports window targeting (frontmost, by_age, by_application, by_title, mouse_position)
minimize             - Minimize a window
	* Supports window targeting
maximize             - Maximize a window
	* Supports window targeting
fullscreen           - Toggle fullscreen mode
	* Supports window targeting
	* [!] Delay when targeting another app (should not require waiting for modifiers to be released)
hide_app             - Hide the active application
	* Supports target: frontmost | specific
	* [TODO] Add "all except Finder" parameter (like quit_app has)
quit_app             - Quit an application
	* Supports target: frontmost | specific | all_except_finder
mission_control      - Show Mission Control
	* Launches Mission Control.app directly, falls back to Ctrl+Up
show_desktop         - Show the desktop
	* Uses DistributedNotificationCenter ("com.apple.showdesktop.awake")
	* [!] Verify this actually works reliably
app_expose           - Show all windows of current application
	* Uses System Events Ctrl+Down; subject to modifier key interference
cycle_window         - Switch to next/previous window [✓ consolidated]
	* Parameters: direction (forward | backward)
	* Uses Cmd+` / Cmd+Shift+`
cycle_space          - Move to next/previous desktop space [✓ consolidated]
	* Parameters: direction (next | previous)
	* Uses System Events Ctrl+Arrow; subject to modifier key interference
lock_screen          - Lock the screen
	* Uses Cmd+Ctrl+Q
sleep_display        - Put display(s) to sleep
	* Uses pmset displaysleepnow
empty_trash          - Empty the trash
	* Uses AppleScript "empty trash without confirm"
	* [!] Verify this works (was previously marked broken)
cycle_profile        - Cycle gesture profiles [✓ consolidated]
	* Parameters: direction (next | previous)
	* Shows notification on switch [✓]
switch_profile       - Switch to a specific gesture profile [✓]
	* Parameters: profile_name (string) [✓ uses name not UUID]
	* [TODO] Switch to dropdown selection

General Core Issues:
	* [TODO] Move window actions (close/minimize/maximize/fullscreen) into Window Management plugin
	* [!] Modifier key interference on System Events actions (app_expose, cycle_space). See to_do.txt.

WINDOW MANAGEMENT (com.mousegestures.window)
------------------------------------------
snap_window          - Move window to a screen region [✓ consolidated from 11 actions]
	* Parameters: position (left_half | right_half | top_half | bottom_half |
	               top_left | top_right | bottom_left | bottom_right |
	               left_third | center_third | right_third)
	* Supports window targeting (frontmost, by_age, by_application, by_title,
	  by_title_contains, all_in_app, all_visible, mouse_position, largest, smallest)
center               - Center window on screen
	* Supports window targeting
resize_to_percent    - Resize window to % of screen [✓ consolidated from resize_25/50/75]
	* Parameters: percent (1-100)
	* Supports window targeting
adjust_size          - Grow or shrink window [✓ consolidated from grow/shrink]
	* Parameters: direction (grow | shrink), percent (1-100)
	* Supports repeat
	* Supports window targeting
	* [!] Actions that only change size should not reposition (currently centers after resize)
cycle_windows        - Cycle through windows [✓ consolidated forward/backward]
	* Parameters: direction (forward | backward)
	* Supports window targeting (by_application cycles within that app's windows)
	* Supports repeat
switch_to_window     - Switch to a specific window
	* Supports window targeting
window_position_memory - Save/restore/delete window position [✓ consolidated]
	* Parameters: operation (save | restore | delete), slot (name)
	* Supports window targeting
window_layout        - Save/restore/delete named window layout [✓ consolidated]
	* Parameters: operation (save | restore | delete), layout_name, reopen_apps (bool)
tile_all             - Tile all windows on screen
	* Parameters: scope (current_app | all_windows)
	* [TODO] Calculate best tiling organization (currently uses sqrt grid)
	* Supports window targeting
cascade              - Cascade windows
	* Parameters: scope (current_app | all_windows) [✓]
	* [!] Should not affect desktop widgets
	* [TODO] Option to resize windows or not
	* [!] Seems to create multiple stacks in weird ways
	* Supports window targeting
set_size             - Set custom window size (px or % of screen)
	* Parameters: width, height, width_percent, height_percent, maintain_aspect_ratio
	* Supports window targeting
	* [TODO] Select type UI improvement
set_position         - Set custom window position
	* Parameters: position_type (absolute | relative | screen_percentage | preset), x, y, preset
	* Supports window targeting
	* [!] Issues with parameter selection UI

Removed:
	* next_display / previous_display [✓ removed]

General Window Issues:
	* [!] Window targeting not working for some actions (works for minimize, not for adjust_size)
	* [!] Window age parameter should be an integer (currently number)
	* [!] Targeting its own window → Fixed: PID guard [✓]

MEDIA CONTROL (com.mousegestures.media)
------------------------------------------
play_pause           - Toggle media playback
	* [!] Uses Space key — only works on active application
next_track           - Skip to next track
	* [!] Uses Cmd+Right — only works on active app, mainly Apple Music
previous_track       - Go to previous track
	* [!] Uses Cmd+Left — only works on active app, mainly Apple Music
	* [TODO] Combine next_track + previous_track → 1 action + direction parameter
volume_up            - Increase volume
	* Parameters: amount (0-100, default 5)
	* Uses AppleScript volume control
	* Supports repeat
volume_down          - Decrease volume
	* Parameters: amount (0-100, default 5)
	* Uses AppleScript volume control
	* Supports repeat
mute                 - Toggle mute state
	* Uses AppleScript
set_volume           - Set volume to specific level
	* Parameters: level (0-100)
	* Uses AppleScript
	* [TODO] Combine volume_up + volume_down + mute + set_volume → 1 action + parameter
fast_forward         - Fast forward playback
	* Parameters: seconds (1-60, default 10)
	* [!] Just sends Right arrow — same as next_track, not real fast forward
	* Supports repeat
rewind               - Rewind playback
	* Parameters: seconds (1-60, default 10)
	* [!] Just sends Left arrow — same as previous_track, not real rewind
	* Supports repeat
	* [TODO] Combine fast_forward + rewind → 1 action + direction parameter

General Media Issues:
	* [!] Media actions use basic keyboard shortcuts, not system media keys (NX_KEYTYPE_*)
	* [!] Most actions only work when targeting the active application
	* [!] Track/seek controls only work in Apple Music

Media:
  next_track + previous_track          → track_skip (direction: next | previous)
  volume_up + volume_down + mute + set_volume → volume_control (operation: up | down | mute | set, amount/level)
  fast_forward + rewind                → seek (direction: forward | backward, seconds)

System:
  brightness_up + brightness_down      → brightness (direction: up | down)
  keyboard_brightness_up + _down       → keyboard_brightness (direction: up | down)
  screenshot_full + _selection + _window + _clipboard → screenshot (type: full | selection | window, destination: file | clipboard)
