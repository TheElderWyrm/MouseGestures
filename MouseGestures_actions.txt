MOUSEGESTURES - ALL AVAILABLE ACTIONS
======================================
Last updated: 2026-03-03

--------------------------------------
CORE ACTIONS (com.mousegestures.core)
--------------------------------------
close_window         - Close a window
minimize             - Minimize a window
maximize             - Maximize a window
fullscreen           - Toggle fullscreen mode
	* Delay when targeting another app (should not require waiting for modifiers to be released)
hide_app             - Hide the active application
	* Add "all except Finder" parameter (like quit_app has)
quit_app             - Quit an application
mission_control      - Show Mission Control
show_desktop         - Show the desktop
	* Verify this actually works reliably
app_expose           - Show all windows of current application
	* Subject to modifier key interference
cycle_window         - Switch to next/previous window (direction parameter)
cycle_space          - Move to next/previous desktop space (direction parameter)
	* Subject to modifier key interference
lock_screen          - Lock the screen
sleep_display        - Put display(s) to sleep
empty_trash          - Empty the trash
	* Verify this works (was previously marked broken)
cycle_profile        - Cycle gesture profiles (direction parameter)
switch_profile       - Switch to a specific gesture profile (profile_name parameter)
	* Switch to dropdown selection

General Core Issues:
	* Move window actions (close/minimize/maximize/fullscreen) into Window Management plugin
	* Modifier key interference on System Events actions (app_expose, cycle_space)

------------------------------------------
WINDOW MANAGEMENT (com.mousegestures.window)
------------------------------------------
snap_window          - Move window to a screen region (position parameter, 11 regions)
center               - Center window on screen
resize_to_percent    - Resize window to % of screen (percent 1-100)
adjust_size          - Grow or shrink window (direction + percent parameters)
	* Actions that only change size should not reposition (currently centers after resize)
cycle_windows        - Cycle through windows (direction parameter)
switch_to_window     - Switch to a specific window
window_position_memory - Save/restore/delete window position (operation + slot parameters)
window_layout        - Save/restore/delete named window layout (operation + layout_name parameters)
tile_all             - Tile all windows on screen (scope parameter)
	* Calculate best tiling organization (currently uses sqrt grid)
cascade              - Cascade windows (scope parameter)
	* Should not affect desktop widgets
	* Add option to resize windows or not
	* Creates multiple stacks in weird ways
set_size             - Set custom window size (px or %)
	* Select type UI improvement
set_position         - Set custom window position (absolute/relative/%/preset)
	* Issues with parameter selection UI

General Window Issues:
	* Window targeting not working for some actions (works for minimize, not for adjust_size)
	* Window age parameter should be an integer (currently number)

------------------------------------------
MEDIA CONTROL (com.mousegestures.media)
------------------------------------------
play_pause           - Toggle media playback
	* Uses Space key — only works on active application
next_track           - Skip to next track
previous_track       - Go to previous track
	* Combine next_track + previous_track → 1 action + direction parameter
	* Only works on active app, mainly Apple Music
volume_up            - Increase volume (amount parameter)
volume_down          - Decrease volume (amount parameter)
mute                 - Toggle mute state
set_volume           - Set volume to specific level (level parameter)
	* Combine volume_up + volume_down + mute + set_volume → 1 action + parameter
fast_forward         - Fast forward playback (seconds parameter)
rewind               - Rewind playback (seconds parameter)
	* Combine fast_forward + rewind → 1 action + direction parameter
	* Just sends arrow keys — same as next/previous track, not real seek

General Media Issues:
	* Media actions use basic keyboard shortcuts, not system media keys (NX_KEYTYPE_*)
	* Most actions only work when targeting the active application
	* Track/seek controls only work in Apple Music

keyboard_brightness_down - Decrease keyboard brightness
	* Not working (uses wrong key codes, may need NX media keys)
	* Combine → 1 action + direction parameter

screenshot_full      - Take a screenshot of entire screen
screenshot_selection - Take a screenshot of selected area
screenshot_window    - Take a screenshot of a window
screenshot_clipboard - Take a screenshot to clipboard (type parameter)

system_sleep         - Put computer to sleep
restart              - Restart the computer (confirm parameter)
shutdown             - Shut down the computer (confirm parameter)
logout               - Log out current user (confirm parameter)
