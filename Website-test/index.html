MouseGestures — Section A/B Test Site

Every section from the two reference builds, numbered and isolated. Where a section differs between builds, switch A ⇄ B to compare in place. Notes save to notes.json on disk.

A = Website-references/v1-original ("Speed of Thought" build — navbar, stats bar, features grid, catalog marquee, 6-item FAQ).
B = Website-references/v2-redesign ("Every Corner" build — swoosh-cursor demo, action tabs, power grid, 8-item FAQ).
Each iframe loads the real, unmodified page for that build with everything but the target section hidden via a small injected script — so behavior (theme toggle, marquee, tabs, hero demo) is exactly as in the source. Run python3 serve.py from Website-test/ (instead of plain http.server) so iframe auto-sizing works and section notes save to notes.json on disk; without it, notes fall back to browser storage only. Preview Mode strips the test-site chrome and stacks whichever variant (A/B) is currently selected for each section into one continuous page — useful for judging how the picked sections read together.
