Questions, answered.

Which Macs does it run on?

MouseGestures requires macOS 13 Ventura or later on Apple silicon. It lives in the menu bar — no Dock icon, no clutter.

Why does it need Accessibility and Automation permissions?

Accessibility lets it watch mouse and keyboard input so gestures can be recognized system-wide; Automation lets it drive actions like volume, brightness, and controlling other apps. macOS asks for both on first run — grant them in System Settings → Privacy & Security. Without them, gestures simply do nothing.

Is the download safe to open?

Yes — the DMG is signed with an Apple Developer ID certificate, built with the hardened runtime, and notarized by Apple, so Gatekeeper verifies it on first launch.

What happens when the 30-day trial ends?

The app keeps working on the Free tier: the core action set and one profile. Your gestures and settings stay put, and upgrading to Pro later re-unlocks everything exactly as you left it.

Why isn't it on the Mac App Store?

The Accessibility access a gesture app needs doesn't fit inside the App Store sandbox. MouseGestures ships as a signed, notarized direct download instead — and that's also why Pro uses a simple offline license key rather than an in-app purchase.

How do updates arrive?

The app checks a static version file and lets you know when a new release is available — downloads come from the project's GitHub Releases page, the same place as the original DMG.

Can I extend it?

Yes. Every built-in capability is itself a plugin, and external .plugin/.bundle files install through the same path. Pro includes the in-app developer tools.
